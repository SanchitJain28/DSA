Dijkstra's Shortest Path Algorithm

Find the minimum-cost path from a source vertex to every other vertex in a weighted graph with non-negative edges.

8 MIN READUPDATED AUG 2026O((V+E) log V)
▶ Launch Visualizer

How it works

Dijkstra's algorithm maintains a set of vertices whose shortest distance from the source is already known. At each step it greedily selects the unvisited vertex with the smallest tentative distance, then relaxes every outgoing edge — updating a neighbour's distance whenever a shorter route through the current vertex is found.

Because edge weights are non-negative, once a vertex is finalized its distance can never improve, which is exactly what makes the greedy choice correct.

Pseudocode

dist[source] = 0
while pq not empty:
  u = pq.extract_min()
  for (v, w) in adj[u]:
    if dist[u] + w < dist[v]:
      dist[v] = dist[u] + w
      pq.decrease_key(v, dist[v])

Key idea

Greedy works only because weights are non-negative. Introduce a single negative edge and you need Bellman-Ford instead.
